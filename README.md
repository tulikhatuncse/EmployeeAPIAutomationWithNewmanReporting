## SQALOGY API AUTOMATION PROJECT WITH Newman Reporting

## About this project
This is employee api automation. This project is faclated to create Employee, update employee, get employee list with different parameter. Here we have create automation and generate a newman report.

## Pre-requisite
-Nodejs

-visual studio code
